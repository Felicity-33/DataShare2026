## 一、作品简介（230 字）

链承共予 · DataShare 是面向个人数据的授权共享与收益结算系统。针对个人数据被无偿收集、授权不透明、用后无法收回、收益归零的痛点，系统把授权与结算规则写进智能合约，数据留在链下。用户端零知识确权、按字段共享给企业，可随时撤销；企业端按合约公开标准价调用，费用先由合约托管，企业确认收货或争议期满后由用户提现，有异议由监管裁决；合约自动记录每次授权、共享与拦截，监管可查证但不可动钱。数据不上链，链上只留索引与摘要，任何人重算即知是否被改——数据不出域、共享可撤销、收益有保障、过程可查证。方案不依赖中心平台，可复用于同类授权场景。

## 三、作品安装说明（366 字）

方案选型：本地链用 Ganache，钱包用 MetaMask，工具链为 Node.js + Hardhat（含 circom2 / SnarkJS）；全部本机运行，链、数据与证明生成都在本地，结果可复现。

①环境：Windows 10 及以上、Node.js 18+、Chrome/Edge + MetaMask；Ganache 固定端口 7545、链 ID 1337，演示账户由本地链预置；

②依赖：项目根目录与 frontend 目录各执行一次 npm install（合约与前端是两套独立依赖树）；

③构建电路与编译合约：先用 circom2 构建零知识电路产物，再用 Hardhat 编译合约——顺序不可颠倒，验证器合约由电路构建生成；

④启动本地链并部署：启动 Ganache，助记词须与 hardhat.config.js 一致（否则派生的账户与 MetaMask 导入的账户对不上）；另开终端执行部署脚本，自动分配角色、为演示字段确权并完成一笔预授权，并打印合约地址与账户地址；

⑤回填、启动与体验：将合约地址写入前端配置，按顺序在 MetaMask 手动导入演示账户私钥；双击 start.bat（或 npm start），自动检查并启动本地链、校验前端所指合约是否存在、启动前端（5174 端口）并打开浏览器，可重复执行；点击「连接钱包」自动切换网络，选择链上身份（用户 / 企业 / 监管）注册后即可体验完整流程。

安装边界：安装依赖需联网，安装完成后运行与演示全部在本机完成；仅当合约代码变更或本地链被重置时才需重新部署。

## 五、设计思路（291 字）

设计目标：让个人数据在可控前提下被企业付费使用——用户掌握数据与授权，企业按需调用、付费有据。核心概念：确权、授权、托管。

必要性与价值：数据只有流动才有价值，流动又意味着失控，故立三条底线——数据不出域、资金有救济、证据不可伪造；用户拿回控制权与收益，企业获得合规数据源。

实现方法与步骤：先定四层结构——链下存数据 → 链上登记索引（数据在哪）→ 链上存摘要与权属承诺（是否被改）→ 链上承载授权、计费、托管、争议与审计规则；再定四条取舍——①存储与索引分离：链上容量宝贵、链下可迁移；②确权用零知识证明：既证明权属又不交密钥，只用在确权这一处；③计价与交付分离：价格写成合约常量、款项先入托管；④裁决权与出款权分离：监管若既是裁判又是收款人，救济便失去可信度；资金路径不交 AI（它无法为错误判断担责）。

## 六、设计重点难点（567 字）

重点：

1. 托管结算：针对付款即到账、交付无保障，采用费用先入合约托管、确认或裁决后结算/退款，实现资金有救济；
2. 存储架构：针对数据上链合规风险，采用链下存数据、链上登记索引与摘要承诺，实现数据不出域且交付可独立验证；
3. 确权机制：针对密钥泄露与冒名风险，采用证明随确权提交、密钥不出本机、钱包签名与链上承诺强绑定，实现杜绝冒名；
4. 审计风控：针对中心化审计易伪造，采用合约完成留痕与拦截、设置信誉分（基线 600，被拦截 −60、败诉 −150，低于 300 暂停调用），实现风控在合约内闭环；
5. 权力分立：针对单点权力过大作恶，采用权限分离（用户能提现不能放款、企业能申诉不能退款、监管能裁决不能动钱）与合约常量定价（业务函数不收价格参数），实现权力制衡；
6. AI 边界：针对 AI 介入资金不确定，采用 AI 只做需求理解与风险提示、定价/扣款/拦截/放款/裁决全由合约执行，实现本地可复现且不依赖外部大模型。

难点：

1. 异常回滚：针对抛异常即回滚导致「先记账再报错」等于没记，采用入口不抛异常、失败先留痕再返回原因，实现交易状态仍成功且以返回值为唯一判据；
2. 验证器陷阱：针对验证器函数体仅内联汇编 return、继承会被判不可达整段删除，采用独立部署与接口外部调用，实现验证器可用；
3. 时间戳冻结：针对本地链空闲不出块导致倒计时锁死，采用本地时间与区块时间戳较大者为基准、发闸门前同步链上时钟，实现倒计时机制有效；
4. 浏览器适配：针对 Node 库直接打包导致浏览器白屏，采用哈希零依赖等价实现（逐位一致）与证明库动态加载，并建静态扫描、服务端渲染、算法一致性、真实浏览器四重自检，实现浏览器正常兼容。
