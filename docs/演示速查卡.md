# 链承共予 · DataShare 演示速查卡（一页纸）

> 现场照这一页做即可。完整分镜脚本与逐字旁白见 `docs/演示视频脚本.md`。
> 流程总览：**用户确权 → 企业充值 → 企业申请 → 用户授权 → 企业调用 → 托管结算 → 用户提现 →（监管审计）**

## 〇、演示前 2 分钟准备

```bash
npm start        # 一键启动本地链 + 前端（固定 5174），并自动打开浏览器
```

浏览器里 MetaMask 切到本地网络：RPC `http://127.0.0.1:7545`、ChainID `1337`。

> ⚠️ **三件不要做的事**
> ① 不要跑 `npm run deploy`（会换合约地址，现有演示数据就看不到了）
> ② 不要重置 Ganache
> ③ 演示数据全部为模拟数据，**不要录入任何真实个人信息**

## 一、总流程（7 步）

| # | 角色 | 操作位置 | 做了什么 |
| --- | --- | --- | --- |
| 1 | 用户 | 我的数据 → 注册新数据字段 | 字段名 + **ZK 权属证明**一起上链（**确权**） |
| 2 | 企业 | 充值押金 | 押金入池，后续调用从这里扣 |
| 3 | 企业 | 数据市场 | 未授权 → 【申请授权】；已授权 → 【直接调用】 |
| 4 | 用户 | 授权申请 | 审批：设有效期 / 次数上限（最小必要、可随时撤销） |
| 5 | 企业 | 数据市场 → 直接调用 | 扣款进**合约托管**，链上留下**交付凭证**（数据摘要哈希） |
| 6 | 用户 | 托管结算 | 挑战期（600 秒）满自动结算 → 【提现】到账 |
| 7 | 监管 | 凭证审计 / 争议裁决 | 可看完整存证，但**看不到链下数据内容** |

## 二、第 1 步详解：演示「上链确权」

**演示时这样说**：原始数据不上链。链上只登记权属承诺，以及后续交付时的摘要哈希。

**操作三步：**

1. 进入「我的数据」→ 选一个「字段分类」（如 `购物偏好`），自定义名留空；
2. 点【上链确权】—— 按钮会依次显示
   「① 正在生成零知识证明…」→「② 证明已生成，等待钱包确认…」
   （**证明在浏览器本地生成**，权属密钥不出本机、也不上链）；
3. 表格出现新行即成功。

> ★ 想换字段演示：换个「字段分类」再来一次即可（共 **17 个分类**可选，见下表）。
> 同名会被前端拦住（加个后缀就行，例如 `消费偏好·2026Q3`）。
> 部署时已预置 4 个字段：用户A 的「消费偏好 / 出行习惯」、用户B 的「消费偏好」、用户C 的「运动健康」。

**可选字段分类（每个分类对应一个链下数据文件，光标停在「字段分类」旁的小问号上有说明）**

| 分组 | 分类 |
| --- | --- |
| 消费行为 | 消费偏好、购物偏好、饮食口味 |
| 生活方式 | 出行习惯、运动健康、兴趣娱乐、阅读学习 |
| 个人属性 | 收入水平、教育背景、职业信息、社交活跃、设备偏好 |
| 财务与家庭 | 金融理财、保险健康、母婴育儿、宠物生活、汽车出行 |

> 想临时再加一个分类：把新的 JSON 文件放进 `frontend/public/data/`，
> 再把分类名加进 `config.js` 的 `DATA_REFS` 与 `UserDashboard.jsx` 的 `FIELD_CATEGORY_OPTIONS` 即可。

## 三、★ 高光点：链下数据 ↔ 链上凭证，可复核

这是「**数据不出域**」最直观的一步：

1. 企业调用成功后，弹窗里以**表格**整齐列出链下数据文件的全部字段
   （分类 / 年龄段 / 消费区间 / 记录条数 / 兴趣标签 / 数据集信息 / 人群画像 / 分类特征 / 字段字典 / 合规声明），
   字段名与内容左右对齐、分组标题分节；表格顶部一行是文件名与「**打开数据文件 ↗**」，可直接打开原始 JSON；同时给出**凭证哈希**；
2. 卡片上会直接显示校验结论：**「链下数据未被篡改」** ——
   它是把链下数据重新计算一遍摘要、再与链上存着的凭证比对得出的；
3. 一句话说法：**链上只有一枚哈希，链下才是真数据；哈希即承诺，任何人可复核。**

## 四、翻车兜底

| 症状 | 原因 | 怎么办 |
| --- | --- | --- |
| 提现按钮是灰的 | 挑战期未满（600 秒） | 等倒计时归零；或让企业点【提前结算】 |
| 提现报"交易失败" | 本地链空闲时时钟被冻结 | 已内置自动同步（点提现会先让链上时钟追上真实时间），再点一次即可 |
| 企业调用被拒 | 押金不足 / 超出授权范围 | 充值押金；按弹窗显示的剩余额度调用 |
| 页面白屏 | 前端代码未刷新 | `Ctrl+Shift+R` 强刷；仍白屏 → `cd frontend && npm run check` |
| 提示「与链上凭证不一致」 | 旧合约时期产生的历史记录 | 正常现象，新产生的调用都会显示「一致」 |
| 「已上链确认条」没弹 | 交易被钱包拒绝 | 重新操作，并在 MetaMask 里确认 |

## 五、可以直接背的三句话

1. 「**链上只存承诺与凭证，原始数据不上链；哈希即承诺，任何人可复核。**」
2. 「**监管可裁决不可动钱、可审计不可窥探** —— 他详细的是「存证」，不是「个人数据」。」
3. 「**AI 只做解读，不参与定价、扣款、放款、裁决**；链上写操作仍然需要人在钱包里确认。」
