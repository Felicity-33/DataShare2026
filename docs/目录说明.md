## 二、各目录详解

### 2.1 `contracts/` —— 智能合约

| 文件 | 职责 | 能否删 |
|---|---|---|
| `DataShare.sol` | **主合约**。三角色权限、数据确权、授权、押金、托管结算、订单、平台分账、监管裁决与信誉分 | ❌ 核心 |
| `IZkVerifier.sol` | Groth16 验证器接口。DataShare 通过它**外部调用**验证器 | ❌ 必需 |
| `ZkVerifier.sol` | Groth16 验证器，由 snarkjs 从电路生成 | ⚠️ 可重建（`npm run build:zk`） |

> ⚠️ **重要**：`ZkVerifier.sol` 生成的 `verifyProof` 函数体只有内联汇编 `return`。
> 若把 DataShare 改成**继承**它并内部调用，编译器会误判"调用之后不可达"，
> 把后续写状态、发事件的代码**整段删掉**（交易成功但什么都没发生）。
> **必须保持"独立部署 + 接口外部调用"的方式。**

### 2.2 `circuits/` —— 零知识证明电路

| 路径 | 说明 | 能否删 |
|---|---|---|
| `dataOwnership.circom` | **权属证明电路源码**：证明「提交者掌握该数据的权属密钥」，`commitment = Poseidon(secret, owner)`，243 个约束 | ❌ 源码 |
| `build/` | 编译产物：`r1cs` / `sym` / `wasm` | ✅ 可重建 |
| `keys/` | Groth16 的 `zkey`（证明密钥）与 `verification_key.json` | ✅ 可重建 |
| `ptau/` | powers of tau（可信设置参数） | ✅ 可重建 |

**重建命令**：`npm run build:zk`（约 15 秒，**不需要联网** —— ptau 是本地生成的）

**自检命令**：`npm run test:zk`（生成证明 → 本地验证 → 确认篡改必被拒）

### 2.3 `scripts/` —— 脚本

| 文件 | 职责 |
|---|---|
| `deploy.js` | 部署脚本：先部署 Groth16 验证器 → 再部署 DataShare → 分配角色 → 用**真实 ZK 证明**确权演示字段 → 预授权 |
| `build-zk.cjs` | ZK 一键构建：编译电路 → 本地生成 ptau → Groth16 setup → 导出验证器 → 拷贝前端产物 |
| `zk-selftest.cjs` | ZK 链路自检（含反例测试） |
| `lib/zk.cjs` | ZK 公共工具（**唯一实现**，部署脚本与测试共用，避免逻辑漂移） |
| `gen-abi.cjs` | **从编译产物自动生成前端 ABI**，根治"手写 ABI 与链上不一致导致静默错解返回值"的老问题 |

### 2.4 `test/` —— 测试

| 文件 | 说明 |
|---|---|
| `DataShare.test.js` | 主业务测试：角色控制 / ZK 确权 / 标准价 / 授权 / 托管结算 / 争议裁决 / 信誉分 / 平台分账 / 订单取消 |
| `zk.test.js` | ZK 专项测试：合法证明通过、篡改公开信号必须被拒、冒名确权被拒、端到端确权 |
| `helpers/zk.js` | 测试用 ZK 工具（转发 `scripts/lib/zk.cjs`） |

**运行**：`npm run test`

### 2.6 `frontend/` —— 前端

│   ├── App.jsx              主控视图（路由、提示系统、登录态）

**前端自检**：`cd frontend && npm run check`（四合一）

> ⚠️ 前置条件：`check:browser` 会用无头 Chrome 真开 `http://localhost:5174/`，**前端服务须在运行**
> （先根目录 `start.bat`，或先 `cd frontend` 再执行 `npm run dev`）。服务没起来时这一项会报页面加载失败。

| 命令 | 作用 |
| --- | --- |
| `npm run check:jsx` | 扫描全部 JSX 文件的未定义标识符（抓构建期不一定报、运行时才炸的笔误） |
| `npm run check:ssr` | Node 侧 SSR 真渲染 8 个主要组件，抓渲染期错误（TDZ 等） |
| `npm run check:poseidon` | Poseidon 实现一致性校验（前端算的承诺必须能被链上验证器接受） |
| `npm run check:browser` | 无头 Chrome 真开页面，抓浏览器专有问题（**SSR 检查抓不到的那一类**） |

> ★ `check:browser` 不可省：构建与 SSR 检查都在 Node 里跑，而浏览器走 `browser` 条件入口。
> 真实事故：`zk.js` 顶层 import `circomlibjs`（需要 Node 的 `Buffer`）→ 浏览器整页白屏，
> 而 `npm run build` 与 `check:ssr` 全部通过。该命令还会逐个 import 三端工作台模块，专治"导入期崩溃"。

## 三、生成物与重建方式

以下目录**可以安全删除**，需要时按命令重建：

| 目录 | 体积 | 重建命令 |
|---|---|---|
| `node_modules/` | 大 | `npm install` |
| `frontend/node_modules/` | 大 | `cd frontend && npm install` |
| `artifacts/` + `cache/` | 2MB | `npm run compile` |
| `frontend/dist/` | 1.1MB | `cd frontend && npm run build` |
| `circuits/build/` + `keys/` + `ptau/` | 11MB | `npm run build:zk` |

## 四、⚠️ 绝对不能删的东西

| 路径 | 原因 |
|---|---|
| `frontend/public/zk/` | 前端生成 ZK 证明依赖它。虽然能通过 `npm run build:zk` 重建，但它属于**运行时依赖**，删了界面确权立即失效 |
| `contracts/DataShare.sol` | 主合约 |
| `circuits/dataOwnership.circom` | 电路源码（丢了要重写） |
| `frontend/src/config.js` | 合约地址 + **由 `npm run gen:abi` 从编译产物自动生成的 ABI**（须与链上版本一致，勿手改） |

## 五、备份注意事项

**必须排除**（否则压缩包体积失控）：
```
node_modules/            frontend/node_modules/
artifacts/               cache/
frontend/dist/           circuits/build|keys|ptau
```

**必须包含**：
```
contracts/  circuits/dataOwnership.circom  scripts/  test/  docs/
frontend/src/  frontend/public/data/  frontend/public/zk/
frontend/jsx-undef-check.mjs  frontend/ssr-check.mjs  frontend/browser-check.mjs
frontend/e2e-check.mjs  frontend/poseidon-check.mjs  frontend/notifications-test.mjs
README.md  start.bat  start.mjs  package.json  package-lock.json
hardhat.config.js  .gitignore
```

按上述规则打包后约 **1.5 MB**（压缩后）。

## 六、日常操作速查

| 我要做什么 | 命令 |
|---|---|
| **启动整套系统** | 双击 `start.bat` 或 `npm start` |
| 跑全部测试 | `npm run test` |
| 只跑 ZK 自检 | `npm run test:zk` |
| 重新编译合约 | `npm run compile` |
| 重新部署（改合约/换链后） | `npm run deploy` |
| 重建 ZK 电路产物 | `npm run build:zk` |
| 前端自检（四合一，改完前端建议跑，需前端服务在跑） | `cd frontend && npm run check` |
| 只做 JSX 未定义扫描 | `cd frontend && npm run check:jsx` |
| 只做 SSR 渲染检查 | `cd frontend && npm run check:ssr` |
| 只做真实浏览器检查 | `cd frontend && npm run check:browser` |
| 合约改动后同步 ABI | `npm run compile && npm run gen:abi` |
